## 💻 Como Executar os Códigos

Para compilar e executar qualquer um dos códigos `.c` localmente, você pode utilizar o `gcc` via terminal:

1. **Navegue até a pasta do arquivo:**
   cd exercicios

2. **Compile o código:**
   gcc 1001.c -o 1001

3. **Execute o programa:**
   - **No Windows:**
     .\1001.exe
   - **No Linux/Mac:**
     ./1001
